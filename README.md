A deterministic Python program that writes a single weird job title — at most 60 characters and nothing else — to /output/entry.txt. The title: a real-sounding director role whose one hilariously specific twist is that its whole job is keeping one office plant alive since 2019.

## Run it

```sh
python3 main.py
```
